Code Academy Website

Project Overview
This project is a responsive Code Academy Website created as part of the Web Development Advanced Midterm Assignment. The website provides information about technology courses and the academy.

Technologies Used
- HTML5 – To create the website structure.
- Bootstrap 5 – To create responsive layouts, cards, buttons, navigation and spacing.
- CSS3 – To add custom colors, styling and hover effects.

Website Sections

1. Header and Navigation
Contains the academy name and navigation links:
- Home
- Courses
- About
- Contact

2. Hero Section
Displays the heading **"Learn Skills. Build Your Future."**, a short description and an Explore Courses button.

3. Courses Section
Displays six technology courses:
- Web Development
- Graphic Design
- Digital Marketing
- Artificial Intelligence
- Cybersecurity
- Freelancing

4. About Us Section
Contains two information boxes:
- Who We Are
- Why Choose Us?

5. Contact Section
Displays the Contact Us heading and email address.

Bootstrap Features Used
- Bootstrap Grid System
- Bootstrap Flexbox
- Bootstrap Cards
- Bootstrap Buttons
- Bootstrap Spacing Classes
- Bootstrap Responsive Classes
- Bootstrap Text and Background Classes

Responsive Design
The website is designed for different screen sizes:
- Desktop: Three course cards per row.
- Tablet: Two course cards per row.
- Mobile: One course card per row.

Bonus Task
An Explore Courses button has been added to the Hero Section. When clicked, it navigates directly to the Courses section.

Project Files
- `index.html` – Main HTML file.
- `style.css` – Custom CSS styling.
- `README.md` – Project documentation.

How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the website and its different sections.
